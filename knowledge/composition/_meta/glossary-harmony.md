# Harmony glossary (ES / EN / DE)

Note names: Spanish Do Re Mi Fa Sol La Si = C D E F G A B; German C D E F G A H, with B = B♭, H = B♮,
sharps "-is" (Fis = F#), flats "-es" (Es = E♭, As = A♭). In Hindemith's Spanish edition an upper-case key name
is major and lower-case is minor ("Mi" = E major, "mi" = E minor); chord letters follow the same rule.
