## 1.2 Orchestral line-ups (plantilla orquestal) (scan p.4–6)

**Concepts**
- Orchestra size naming (a dos / a tres / a cuatro): named after how many of each woodwind there are. From
  the mid-18th c. woodwinds always come at least in pairs.
- Orchestra "a dos" (orquesta a dos), c.1750–1830: strings + 2 fl, 2 ob, 2 cl, 2 bsn + some brass
  (usually 2 horns; toward the 19th c. trumpet and trombone) + timpani.
- Orchestra "a tres" (orquesta a tres), c.1830–1890: strings + woodwinds in threes, either 3 of each or
  2 + a family auxiliary (2 fl + piccolo, 2 ob + English horn, 2 cl + bass clarinet, 2 bsn + contrabassoon)
  + 4 horns, 2 trumpets, 2 trombones + bass trombone + timpani.
- Orchestra "a cuatro" (orquesta a cuatro), c.1900–today: strings + woodwinds in fours (3 fl + piccolo,
  3 ob + E.H., 3 cl + bass cl, 3 bsn + contrabsn) + 6–8 horns, 4 trumpets, 3 trombones + bass trombone,
  tuba + timpani, keyboards, metal-plate (mallet) instruments, membranophones, etc.

**Standard stage layout (Figura 1, standard from 2nd half of 18th c.)**, audience view, left→right:
- Front arc: 1st violins (far left) | violas (centre-left) | cellos (centre-right) | 2nd violins (far right).
- Double basses behind the 2nd violins/cellos on the right. Harp and piano at left, behind 1st violins.
- Woodwind row 1 (front): piccolos, flutes, oboes, English horn. Row 2: horns, clarinets, bassoons,
  contrabassoons. Back row: percussion, timpani, trumpets, trombones, tubas. Organ at far right.

**Agent applicability**
- Use the period line-up to pick a track template: Classical (a2) ≈ 2 fl/ob/cl/bsn, 2 hn, (2 tpt), timp,
  strings; Romantic (a3) adds picc/E.H./bass cl/contrabsn, 4 hn, 3 tbn; 20th c. (a4) adds tuba, 6–8 hn, perc.
- Default pan map from Fig. 1 (inferred): Vln I hard-ish left, Vla centre-left, Vc centre-right, Vln II right,
  Cb right-rear; harp/piano left; woodwinds near centre, brass/percussion centre-rear.

## 1.3 Notation conventions by family (lectoescritura por familias) (scan p.6–8)

**Rules**
- R1 [MUST] Each string group (Vln I, Vln II, Vla, Vc, Cb) is a *section* playing one line; split it only
  with an explicit divisi (div.) marking.
- R2 [ALLOWED] Strings can play double/triple/quadruple stops (dobles/triples/cuádruples cuerdas), but not
  freely like piano/guitar: feasibility depends on the note combination and the open strings. (See Tema 4.)
- R3 [MUST] Woodwinds and brass play individually (in pairs etc.), so the score states which player plays
  each line: Roman numerals I., II., III. (Arabic 1º, 2º since late 19th c.).
- R4 [MUST] When several winds play the same line in unison, mark it a 2, a 3, a 4.
- R5 [ALLOWED, style] Baroque/Classical timpani were hand-tuned to only **two notes** that normally did not
  change during the whole work; only with 20th-c. pedal timpani can any note be played. *Why:* historical
  tuning mechanism (Mozart "Jupiter" example).

**Agent applicability**
- For Classical-style pieces give timpani only tonic + dominant (two fixed pitches) (inferred from R5).
- In a sample-library setup, a wind "a 2" line = one patch at doubled dynamic/ensemble patch, not divisi.

## 1.4 Clefs per instrument (claves) (scan p.8–11)

**Concepts**
- Reading orchestral parts needs at least four clefs: treble (sol en 2ª), bass (fa en 4ª), alto (do en 3ª),
  tenor (do en 4ª). Some instruments switch clef by register.

**Rules (clef table, figures p.9–11)**
- Strings: violin = treble; viola = alto, occasionally treble; cello = bass, occasionally tenor;
  double bass = bass, **sounds an octave lower than written**.
- Woodwinds: piccolo (flautín) = treble, **sounds an octave higher**; flute, oboe = treble; English horn,
  Bb clarinet, A clarinet, Eb clarinet, bass clarinet = treble, all **transposing**; bassoon = bass,
  occasionally tenor; contrabassoon = bass, **sounds an octave lower**.
- Brass: trumpet = treble (transposing); horn = treble (transposing); tenor trombone = bass and tenor,
  **non-transposing**; bass trombone = bass, labelled in the source "reading: an octave lower" [source
  claim; standard practice is non-transposing; treat as doubtful (inferred)]; tuba = bass.
- Percussion/keyboards: timpani = bass; keyboard instruments and harp = grand staff (treble + bass).

## 1.5 Transposing instruments (instrumentos transpositores) (scan p.11–15)

**Concepts**
- Transposing instrument: the sounding (real) note differs from the written note, for historical reasons.
- Named by the pitch that sounds when a written C is played (in Bb: written C sounds Bb).
- Transposition only affects some woodwinds and brass: clarinet family (Bb, Ab [as printed], bass, Eb/
  requinto), English horn, horns, trumpet and flugelhorn, saxophones (alto, tenor, baritone).

**Rules: written vs sounding (reading = go DOWN from written; writing = go UP from concert)**
- R1 [MUST] Bb instruments (Bb clarinet, trumpet in Bb, flugelhorn (fliscorno), tenor sax) sound a **major
  2nd (2 st) below** written. Write them 2 st higher. Figure: written D4 → sounds C4.
- R2 [MUST] Bass clarinet (treble notation) sounds a **major 9th (14 st) below** written. Figure: written
  D5 → sounds C4. (The summary table lists it simply among the Bb instruments; the chart gives the 9th.)
- R3 [MUST] A clarinet sounds a **minor 3rd (3 st) below**: written Eb4 → C4; written C5 → A4.
- R4 [MUST] Eb clarinet (requinto) is the exception: sounds a **minor 3rd (3 st) ABOVE** written:
  written A3 → sounds C4; written C5 → sounds Eb5.
- R5 [MUST] F instruments (horn in F, English horn) sound a **perfect 5th (7 st) below**: written G4 → C4.
- R6 [MUST] G instruments (alto flute, "flauta en sol") sound a **perfect 4th (5 st) below**.
- R7 [MUST] Eb saxophones/Eb group: the summary table says "major 6th (9 st) below" for alto sax, baritone
  sax and requinto. *Caveat:* this conflicts with R4 for requinto; baritone sax actually sounds an octave +
  M6 (21 st) below (inferred, standard practice).
- R8 [MUST] Historical horn crooks (trompa en …), written C5 / written note → sounding C4: horn in C =
  octave (12 st) below (written C5); in D = minor 7th (10 st) below (written Bb4); in Eb = major 6th (9 st)
  below (written A4); in E = minor 6th (8 st) below (written Ab4); in F = P5 (7) below (written G4); in G =
  P4 (5) below (written F4); in A = minor 3rd (3) below (written Eb4); in Bb (alto) = major 2nd (2) below
  (written D4).
- R9 [MUST] Key signature of a transposing part = concert key transposed UP by the instrument's interval
  ("armadura respecto a la tonalidad principal"): Bb → +M2, A → +m3, G → +P4, F → +P5, Eb → +M6.
- R10 [ALLOWED, style] From c.1850 transposing instruments are increasingly written at concert pitch
  ("nota real"), per the summary box.

**Examples**
- Beethoven, Pastoral Symphony (F major): Bb clarinet part in G major (+M2); horn in F part in C (+P5).
- Brahms, Symphony 4 (E minor): A clarinet part a m3 up (G minor); horn in E part written a m6 up (C).

**Agent applicability**
- MIDI in REAPER is concert pitch: never apply written transpositions to notes. Use the table only when
  reading a score/part into MIDI: subtract the interval (e.g., Bb clarinet written D5 → MIDI 72 = C5).
- When exporting/annotating parts for players, add the interval: Bb +2, A +3, F +7, Eb alto sax +9,
  Eb clarinet −3, bass clarinet +14, piccolo −12 (sounds 8va), contrabass/contrabassoon +12.
- Trombones and strings except double bass: no transposition.
