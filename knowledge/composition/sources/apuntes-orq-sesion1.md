# Apuntes de orquestación: Primera sesión

## Bibliographic info
- Course class notes (Spanish), "Primera sesión", 6 scanned pages, plus PDF1 "La orquesta en la
  actualidad" (1 page, English table). PDF2–PDF4 (transposition chart, parts, score) are referenced but
  not included. Author and course name are not stated. Reference text cited: Samuel Adler, *The Study of
  Orchestration*.
- Source id: `apuntes-orq-sesion1`. There are no printed page numbers, so notes cite `scan p.N` and `PDF1`.

## Scope
- 1A: the orchestra today, volume vs type of sound, recording practice (section-by-section sessions),
  balanced string proportions table, what N players per part sound like.
- 1B–1D: clefs, transposing instruments (the in-staff = good-register heuristic), score and parts.
- 2: strings, violin and viola only (open strings, per-string spans, practical upper limits, roles).
  The notes stop after the viola.
- Style scope: modern orchestral and recording practice (film/media sessions included).

## Reliability
- Practical, session-oriented, consistent with Adler. Good for balance and section-size decisions.
- **Octave convention:** the notes use middle C = C3. The digest converted everything to C4 = 60.
- One table cell is ambiguous: mid-thin basses "1/3". The viola alternative counts in parentheses have an
  unseen footnote. Both are marked `[?]` in the digest.
- Sample-patch mapping (solo / chamber / section) is an inference added in the notes, not in the source.
